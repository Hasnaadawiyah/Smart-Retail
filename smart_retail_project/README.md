# Smart-Retail - Final Project Dasar Pemrograman

Aplikasi kasir sederhana berbasis Python dan SQLite untuk studi kasus Toko Maju Jaya.

## File
- `main.py` - source code utama.
- `smart_retail.db` - database SQLite.
- `README.md` - panduan penggunaan.

## Akun demo
- Admin: `admin` / `admin123`
- Kasir: `kasir` / `kasir123`

## Menjalankan program
Pastikan Python sudah terpasang, lalu jalankan:

```bash
python main.py
```

Database akan dibuat/diinisialisasi otomatis jika belum ada.

## Fitur
- Login admin dan kasir.
- CRUD produk.
- Pencarian produk berdasarkan nama atau ID.
- Transaksi penjualan dengan keranjang.
- Validasi stok.
- Pembayaran dan kembalian.
- Update stok otomatis.
- Riwayat transaksi.
- Laporan penjualan.
- Produk terlaris.
- Informasi stok kurang dari 10.
